Course by course

CS 7650 · Summer 2026

Natural Language Processing

This course built language systems from the ground up across six PyTorch programming assignments, implemented by hand without high-level NLP libraries or AI coding assistants.

What I built

  • Built a neural-network primer and trained text classifiers to sort movie reviews by sentiment.
  • Implemented next-word language models from scratch across two progressive assignments.
  • Trained word embeddings from surrounding word context (distributional semantics).
  • Designed and shipped an end-to-end mini-project: an attention-based key-value memory network that answers questions by retrieving facts from external Wikipedia biographies. I handled data preparation, the training loop, test suites, and experimental write-up.

Carried into my work. Combining this course with Andrej Karpathy's Zero to Hero series gave me hands-on implementation experience with language models and attention mechanisms. Next, I plan to adapt those sequence tools to biological data by tokenizing continuous animal behavior into discrete symbols, extending the movement syllables in The grammar of movement.

  • Python
  • PyTorch
  • Text classification
  • Language models
  • Word embeddings
  • Attention

CS 7641 · Spring 2026

Machine Learning

This survey course centered on four hypothesis-driven experimental reports backed by Python benchmarks in scikit-learn, PyTorch, and Gymnasium. Using two public datasets—census income and wine quality—I wrote down falsifiable hypotheses before running experiments and analyzed where each algorithm succeeded or broke.

What I built

  • Supervised learning: Benchmarked decision trees, k-nearest neighbors, support vector machines, and neural networks under strong class imbalance.
  • Optimization: Compared neural-network optimizers head to head, from plain stochastic gradient descent through momentum, RMSProp, Adam, and AdamW.
  • Unsupervised learning: Evaluated clustering methods (k-means, Gaussian mixtures) alongside dimensionality reduction (PCA, ICA, random projection).
  • Reinforcement learning: Contrasted model-based planning (value and policy iteration) against model-free learning from experience (SARSA, Q-learning) in Blackjack and CartPole.

I paired every report with a reproducibility manifest listing the exact code commits, environments, random seeds, and run commands needed to regenerate every figure.

  • Python
  • scikit-learn
  • PyTorch
  • Gymnasium
  • Experiment design
  • Reproducibility

CS 7646 · Spring 2025

Machine Learning for Trading

Financial time series expose overfitting quickly because the only honest test set is the future. Across eight Python projects, I built a modular trading-research toolkit and documented each experiment like a journal article.

What I built

  • Simulated a roulette betting strategy via Monte Carlo experiments to quantify variance and bankroll risk.
  • Implemented decision trees, random trees, and bagged ensembles from scratch in NumPy.
  • Built a portfolio optimizer, technical indicators, and a market simulator that incorporates trading costs.
  • Trained a reinforcement-learning agent using Q-learning with Dyna-Q planning.
  • Benchmarked a hand-designed trading strategy against a bagged random-tree ensemble on a strictly held-out future period.
  • Python
  • NumPy
  • pandas
  • Ensemble learning
  • Reinforcement learning
  • Backtesting

ISYE 6420 · Fall 2024

Bayesian Statistics

This course derived Bayesian inference from first principles: priors, conjugate models, Markov chain Monte Carlo (Metropolis and Gibbs sampling), hierarchical linear models, missing-data imputation, survival models, and posterior model checking.

What I built

  • Completed six applied modeling problem sets in Python using PyMC and ArviZ.
  • Executed an open-ended final project applying Bayesian hierarchical models to my lab's data to test whether postnatal Zika virus infection alters infant rhesus macaque calls—work that grew directly into What a scream carries.

  • MCMC
  • Hierarchical models
  • Python
